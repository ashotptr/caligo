# YouTube Spam Collection

Comments from five music videos (Psy, Katy Perry, LMFAO, Eminem, Shakira), labelled spam (1) or not (0).

- Source: UCI Machine Learning Repository, https://archive.ics.uci.edu/dataset/380/youtube+spam+collection
- Authors: Túlio C. Alberto, Johannes V. Lochter, Tiago A. Almeida. "TubeSpam: Comment Spam Filtering on YouTube", IEEE ICMLA 2015.
- License: CC BY 4.0.
- Change: only the comment text and its label are kept. Comment IDs, author names and dates are removed.
